# India Zoho Books customisation: fixed-price project quotes (INR, 2025-2026)

Evidence quality: nearly all figures come from partner/agency marketing blogs (commercial interest, no cited methodology, internal inconsistencies). No independent survey, Clutch/GoodFirms/IndiaMART/Zoho-community price threads were found within the search budget. All partner figures are ex-GST; 18% GST applies on top.

## Typical price ranges for Zoho Books implementation, Deluge functions, workflow automation, API integration

### Takeaway
Zoho Books partner-only implementation is quoted at roughly Rs 40k-90k (small) to Rs 2-5 lakh+ (enterprise); a single Deluge function Rs 10k-40k, complex Deluge business logic Rs 50k-2 lakh, custom API integration Rs 25k-1.5 lakh. Only one vendor (Codroid) gives per-item figures, and they are not independently corroborated.

### Cited Findings
- Zoho Books fixed implementation fee, partner fees only (excl. licences), Jul 2026: small (up to 25 users) Rs 40,000-90,000; mid (25-100) Rs 90,000-2,00,000; enterprise (100+) Rs 2,00,000-5,00,000+. Zoho Creator custom app small Rs 80k-2 lakh, mid Rs 2-5 lakh — [Aaxonix, 20 Jul 2026](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/)
- Aaxonix: custom integrations Rs 30,000-1,50,000 per integration; complex approval chains and Deluge scripting add to the fee (no per-function price) — [Aaxonix](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/)
- Codroid Labs (15 Jul 2026, CRM-focused guide; prices ex-GST): Deluge custom function Rs 10,000-40,000; complex Deluge scripting (business rules) Rs 50,000-2,00,000; single workflow rule (3-5 actions) Rs 2,000-5,000; automation bundle of 10-15 rules Rs 20,000-40,000; approval workflows (discount/contract/finance) Rs 30,000-60,000; custom API integration (any system) Rs 25,000+; WhatsApp Business API Rs 10,000-50,000 (another section of the page says 10,000-25,000); Razorpay/PayU Rs 10,000-30,000 (another section 10,000-20,000); IndiaMART API Rs 10,000-15,000; Tally Rs 30,000-1,50,000; ERP (SAP/Oracle) Rs 50,000-5,00,000 (search snippet of the same guide said 1,00,000-5,00,000 for SAP/Oracle/Tally/custom ERP); telephony Rs 15,000-75,000 — [Codroid Labs](https://codroiditlabs.com/how-much-does-zoho-crm-implementation-cost-in-india/)
- Codroid Zoho One guide (18 Dec 2025): small business (5-20 users) implementation Rs 1.5-3.5 lakh; SME range Rs 1.5-8 lakh+; Deluge scripting and integrations named only as cost factors — [Codroid Labs](https://codroiditlabs.com/?p=3940)
- Digiwah: Rs 35,000 (5-user starter) to Rs 4 lakh+ (enterprise Zoho One); fixed price set after a discovery "Blueprint" phase; WhatsApp Business API integration included in every implementation; no Books-specific price — [Digiwah](https://digiwah.com/zoho/)
- Chennai-area partner (via search summary, page not fetched): Rs 39,999 one-time Books implementation package, GST and subscription extra — [Precision Tech](https://precisiontech.in/software/zoho/zoho-books/)
- IncorpX (Zoho authorized partner, per search summary; page returned 403 on fetch): Rs 4,999 one-time implementation incl. 2 training sessions + runbook, waived with monthly plan from Rs 1,999; Tally/Excel migration from Rs 9,999 — [IncorpX](https://www.incorpx.io/zoho-books-accounting-services)

### Inferences
- A realistic Books-only customisation (a few custom functions + 10-15 workflow rules + 1-2 integrations) sums, on Codroid/Aaxonix per-item rates, to about Rs 60k-2.5 lakh before GST; freelancers would undercut this.
- Per-item prices are mostly CRM-derived; Books-specific equivalents were not published.

### Gaps
- No Books-specific per-function or per-web-tab/custom module price found; no Clutch/GoodFirms/IndiaMART/JustDial/UrbanPro/Reddit/Zoho community price data retrieved.
- Aaxonix and Codroid are the same genre of SEO marketing content; no primary quote documents (invoices, proposals) found.

## Pricing models (fixed / T&M / per-day), AMC and support percentages

### Takeaway
Fixed-price with milestones is the commonly described model for standard scope; T&M day/hour rates are used for integrations. Support is sold as monthly retainers or yearly packs; no published AMC as % of project fee was found.

### Cited Findings
- Day rate Rs 3,500-12,000 per consultant day by seniority/tier; fixed-fee with milestones (config, migration, training, go-live) is common; Aaxonix warns against partners defaulting to T&M for simple Books/CRM projects — [Aaxonix](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/)
- Hourly: $20-45/hr for Indian partners on standard config — [RaftLabs, Jul 2026](https://www.raftlabs.com/blog/top-zoho-development-companies); $25-80/hr (body) vs $40-80/hr (FAQ) on the same page — [Codroid Labs](https://codroiditlabs.com/?p=3940); integration work $60-90/hr community-reported, one quote ~$9,000 for 130 hours — [Aaxonix](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/)
- Monthly retainers: Rs 15,000 (basic) to Rs 60,000+ (active development) — [Aaxonix](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/); Digiwah managed services Rs 25,000-1,00,000/month, 30-day hypercare included — [Digiwah](https://digiwah.com/zoho/)
- Yearly support/AMC packs (Codroid, ex-GST): Basic Rs 20,000-50,000; Priority SLA Rs 50,000-1,50,000; Enterprise dedicated Rs 1.5-3 lakh+ — [Codroid Labs](https://codroiditlabs.com/how-much-does-zoho-crm-implementation-cost-in-india/)
- Training: extra sessions Rs 8,000-20,000 each (Aaxonix); admin session Rs 5,000-10,000, multi-team Rs 15,000-40,000 (Codroid); Excel to Zoho migration Rs 15,000-50,000 (Codroid) — sources as above
- Books migration from other accounting tools: Patron Accounting Tally-to-Zoho from Rs 14,999 single company (3-14 days), QuickBooks-to-Zoho from Rs 9,999, ex-GST — [Patron Accounting](https://www.patronaccounting.com/migration-from-tally-to-zoho/delhi)

### Inferences
- Implied AMC as % of project fee: Codroid basic Rs 20-50k/yr against Rs 40-90k small project is roughly 30-60%, but this is my arithmetic, not a published percentage.

### Gaps
- No published AMC percentage (e.g. 15-20% of project value) from any Indian partner found.

## Zoho's own price lists, support, GST

### Takeaway
Zoho publishes support pricing for Books India (Premium 20% of subscription, minimum Rs 40,000/yr) but no implementation/consulting rate card was found.

### Cited Findings
- Zoho Books India support: Basic free (free plan), Classic free (paid plans), Premium Rs 4,000/month or Rs 40,000/year or 20% of subscription, whichever is higher; "exclusive of local taxes" — [Zoho Books support pricing](https://zstatic.zohostatic.com/in/books/support-pricing/)
- 18% GST applies to implementation fees from registered Indian IT service providers — [Aaxonix](https://aaxonix.com/resources/zoho-implementation-partner-cost-india/)
- Books subscription prices conflict across sources (Standard Rs 899 vs Rs 1,680; Professional Rs 1,499 vs Rs 2,800 per org/month) — [Patron Accounting](https://www.patronaccounting.com/blog/zoho-books-pricing-india-2026) vs [Precision Tech](https://precisiontech.in/software/zoho/zoho-books/); verify on zoho.com/in/books/pricing
- Zoho One licence Rs 2,500-3,500/user/month (Aaxonix) vs Rs 1,250 all-employee / Rs 3,500 flexible (Codroid)

### Inferences
- Zoho Premium support is a vendor support add-on, not a customisation rate; it is a useful benchmark for "support = ~20% of subscription".

### Gaps
- No Zoho-published consulting/implementation price list; Zoho Premium Partner rate cards not found.

## Typical total SME budget for Books customisation

### Takeaway
Published small-business implementation totals run Rs 40k-3.5 lakh (partner fees); Books-only small Rs 40k-90k; adding custom functions/integrations plausibly pushes to Rs 1-3 lakh, plus 18% GST and Rs 20k-1.5 lakh/yr support.

### Cited Findings
- See ranges above: Aaxonix Books small Rs 40k-90k, mid Rs 90k-2 lakh; Codroid small 5-20 users Rs 1.5-3.5 lakh (Zoho One-oriented); Digiwah from Rs 35k; Precision Tech Rs 39,999 package.

### Inferences
- Reasonable planning band for a Books-only customisation project: Rs 75k-2.5 lakh ex-GST (about Rs 90k-3 lakh incl. GST), plus Rs 20k-50k/yr basic support. This is my synthesis, not a quoted figure.

### Gaps
- No real SME case study with actual invoiced cost found.
